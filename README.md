# ダッシュダービー

iPad / iPhone で遊べる、オフラインのレース予想パーティーゲーム。1台の端末を回して 2〜4 人で遊ぶ。

- 各プレイヤーがこっそり 1着・2着を予想
- レースは自動で進む。カードが1枚ずつめくられ、転倒・逆走・コースアウト、突然のイベント（追い風・ぬかるみ など）が起きる
- 1着的中 5点、2着的中 3点、両方的中で +2点。全3レースで最終レースは得点2倍

## 遊び方（iPad）

1. Safari で GitHub Pages の URL を開く
2. 共有ボタン →「ホーム画面に追加」
3. 以後はオフラインでもホーム画面から起動できる

## 開発

```sh
npm install
npm run dev    # 開発サーバー
npm test       # ルール処理のテスト
npm run build  # dist/ に出力
```

ルール処理は `src/engine.ts`（画面に依存しない）、画面は `src/main.ts`。
